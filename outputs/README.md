## Regenerate

Run `notebooks/01_data_visualization_assignment.ipynb` from top to bottom. The notebook writes all PNGs and `KEY_FINDINGS.md` to this folder. The first load of Seaborn's built-in `taxis` dataset may require internet access.

The key findings report is generated from the cleaned dataset each time; it is not a manually maintained set of fixed statistics.
